# 🥬 Green Crate – Organic Products Store

A beautiful, responsive, and fast organic products storefront built with **React**, **TypeScript**, and **Vite**. Deployed on **Netlify**.

> 🌿 Discover the freshest, healthiest, and most delicious organic snacks!

## 🔗 Live Demo

👉 [green-crate.netlify.app](https://green-crate.netlify.app/)

---

## ✨ Features

- 🍏 Clean, modern product cards with organic labeling
- 🛍️ Product showcase with hover animations and smooth transitions
- 📜 Customer testimonials section with star ratings
- 📱 Fully responsive design
- ⚡ Super-fast performance with Vite
- 🎨 TailwindCSS styling
- 🎞️ Scroll-triggered animations via GSAP
- 🧊 Interactive 3D Product View: Enhance product engagement with immersive Three.js-powered 3D models right on the product page.

---

## 📦 Tech Stack

- **React + TypeScript**
- **Vite**
- **TailwindCSS**
- **Three JS**
- **GSAP** for animation
- **Lucide Icons**
- **React Router DOM**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/green-crate.git
cd green-crate
2. Install dependencies
npm install
3. Start the development server
npm run dev
Open http://localhost:5173 to view it in your browser.

🏗️ Build for Production
npm run build
Builds the app for production to the dist folder.

Preview the production build locally:
npm run preview
🌐 Deployment

The project is deployed on Netlify. Simply drag the /dist folder or connect your GitHub repo.
